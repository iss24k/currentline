# Travel sequences

The tour is a composite power path. Distance labels on the plant, facility and server links describe illustrative spans at the scale shown. The films compress both time and framing. The moving light represents energy transfer through each medium.

## Transmission scale

The long-distance sequence uses the documented length of Bonneville Power Administration’s existing McNary–Roundup No. 1 line in Umatilla County, Oregon. It operates at 230 kV and covers 38.5 miles, or about 62 km. [Bonneville Power Administration project description](https://www.bpa.gov/learn-and-participate/public-involvement-decisions/project-reviews/mcnary-roundup-transmission-line-rebuild)
